# ⏱️ Focusflow

> A beautiful Pomodoro-style study planner — built with pure HTML & Tailwind CSS.

## ✨ Features

- 🍅 **Pomodoro Timer UI** — 25:00 static timer with a beautiful CSS conic-gradient progress ring
- 📋 **Study Planner** — Task cards with active, pending, and completed states
- 🎯 **Month Goals** — Checklist-style goal tracker
- 📊 **Quick Stats** — Daily focus stats at a glance
- 🎨 **iDraft-inspired Design** — Clean black & white monochromatic glassmorphism UI
- 📱 **Fully Responsive** — Works seamlessly on desktop and mobile
- ⚡ **Zero Dependencies** — Just HTML + Tailwind CDN, no build step needed

---

## 🎨 Design System

| Element | Value |
|---|---|
| **Background** | Frosted gray gradient |
| **Primary Cards** | White glassmorphism (`rgba(255,255,255,0.55)`) |
| **Timer Card** | Dark glass (`rgba(20,20,22,0.88)`) |
| **Accent** | Pure black & white monochromatic |
| **Font** | Inter (Google Fonts) |
| **Border Radius** | `rounded-3xl` (24px) |

## 🚀 Getting Started

No installation needed! Just open the file directly:

```bash
# Clone the repository
git clone https://github.com/anuskasinha18-boop/Focusflow.git

# Open in browser
cd Focusflow
start index.html   # Windows
open index.html    # macOS
```

Or simply double-click `index.html` to open it in your browser.

## 🖼️ UI Sections
