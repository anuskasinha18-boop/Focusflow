# 🎯 Focusflow

> A beautifully designed Pomodoro Timer + Study Planner built with pure **HTML** and **Tailwind CSS**.

![Focusflow Preview](./preview.png)

---

## ✨ Features

- ⏱️ **Pomodoro Timer UI** — Clean 25:00 countdown display with a CSS-only circular progress ring
- 📋 **Study Planner** — Task board with Active, Pending, and Completed states
- 🎯 **Month Goals** — Checklist-style goal tracker for the month
- 📊 **Quick Stats** — Done, Active tasks & streak counter at a glance
- 🖤 **iDraft-inspired Design** — Monochromatic black & white glassmorphism aesthetic
- 📱 **Fully Responsive** — Works on all screen sizes

---

## 🎨 Design System

| Element | Value |
|---|---|
| Font | Inter (Google Fonts) |
| Theme | Black & White Monochromatic |
| Style | Glassmorphism / Frosted glass |
| Framework | Tailwind CSS (CDN) |
| Background | Soft gray radial gradient |

## 🚀 Getting Started

No build tools needed. Just open the file directly in your browser:

```bash
# Clone the repo
git clone https://github.com/anuskasinha18-boop/Focusflow.git

# Navigate into the folder
cd Focusflow

# Open in browser
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

Or simply **double-click** `index.html` in your file explorer.
